📌 About the Project

Quick Basket is an online shopping application designed to make product browsing and shopping easier, faster, and more convenient. It provides a simple interface for exploring products and viewing product information.

Developed using the .NET technology stack, this project demonstrates web application development concepts and provides a foundation for building a feature-rich e-commerce platform.

🎯 Mission

To make everyday shopping simple, accessible, and convenient through technology.

🛍️ Product Browsing — Explore available products.

🚀 Getting Started

Follow these steps to run the project locally.

📋 Prerequisites
.NET SDK compatible with the project
Visual Studio or Visual Studio Code
SQL Server, if required
1️⃣ Clone the Repository
git clone https://github.com/Ankitpandeyup51/Quick_Basket.git

2️⃣ Navigate to the Project Folder
cd Quick_Basket

3️⃣ Restore Dependencies

Run this command from the directory containing the .csproj file:

dotnet restore

4️⃣ Run the Application

Navigate to the startup project's directory and execute:

dotnet run


Open the local URL displayed in the terminal to access the application.

Note: Database configuration and other application settings may be required. Commands can vary depending on the project structure.
